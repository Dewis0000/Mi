# StreOps — полный список функционала

Платформа для Twitch-стримеров: чат-бот, модерация, музыка, виджеты для OBS,
донаты, аукционы и админ-панель. Работает на Cloudflare Workers (`zaka-bot`)
+ Durable Objects (по одному на канал) + KV-хранилище. Домен: `streops.ru`.

---

## 1. Вход и аккаунты

- **Вход через Twitch OAuth** — основной способ. При первом входе:
  - создаётся конфиг канала по умолчанию;
  - боту (`zaka_bot`) автоматически выдаётся модератор на канале;
  - бот сразу подключается к чату этого канала.
- **Вход по паролю в обход Twitch** (`/admin-login`) — отдельный вход для
  владельца: email `admin@gmail.com` / пароль, создаёт сессию суперадмина
  (`zaka_00`). Защищён лимитом попыток (5 неверных с одного IP → блок на
  15 минут). Ссылка нигде не показывается в интерфейсе.
- **Суперадмин** (`zaka_00`) — единственный аккаунт с полным доступом,
  освобождён от всех ограничений модерации и заказа треков.
- **Гибрид Pro/Free/тарифы** — `free`, `pro`, `pro-plus`, `ultimate`
  (сейчас все платные уровни дают одинаковый набор функций — 4 доп. правила
  модерации; названия статусные).
- **Бан аккаунта на сайте** (site-ban) — админ может полностью заблокировать
  доступ пользователя к личному кабинету, с указанием причины.
- **Уведомления** — всплывающие уведомления в личном кабинете со звуком,
  рассылаются админом (всем или конкретному пользователю), есть счётчик
  непрочитанных.

---

## 2. Главная (Overview)

- Реальная статистика с Twitch: подписчики, фолловеры, followers/subs за
  неделю (Δ), очки подписки — только с согласия стримера (отдельный OAuth
  токен broadcaster'а с нужными scope).
- Реальные графики активности (не заглушки).
- Статус бота (подключён/нет), статус стрима (live/offline, зрители,
  игра, название) — напрямую из Twitch Helix.
- Кнопки старт/стоп бота, "Проверить подключение" (тестовое сообщение).

---

## 3. Модерация

- **Стоп-слова** — список запрещённых слов.
- **Капс-фильтр** — вкл/выкл.
- **Режим ссылок** — разрешены всем / только подписчикам / только модераторам.
- **Реальная эскалация нарушений**:
  - N предупреждений до тайм-аута (настраивается),
  - длительность тайм-аута,
  - бан после N тайм-аутов,
  - "первое нарушение сразу" — обход всей лестницы для конкретного правила.
- **Индивидуальные исключения по зрителям** — конкретный ник либо полностью
  исключён из модерации, либо "банить всегда".
- **Pro-правила** (только на платных тарифах, каждое можно включить/выключить
  отдельно):
  - проверка на дубли сообщений,
  - флуд одинаковыми эмодзи,
  - спам-упоминаниями (@mention flood),
  - оскорбления/токсичность — реальная проверка через ИИ (Llama Guard 3
    через Cloudflare AI, бесплатная квота 10 000 запросов/день).
- **Ручной бан/разбан в чате** — с канала, с указанием ника, длительности,
  причины (реальный вызов Twitch Moderation API, не только локальная база).
- **Платформенный чёрный список** — юзернейм, добавленный админом сюда,
  бот банит на ЛЮБОМ подключённом канале, куда бы он ни зашёл.
- **Очистить чат** / **Режим только эмодзи** — реальные Twitch-команды
  модерации (через права бота).
- **Журнал (Logs)** — реальный лог действий бота и модерации, кнопка
  "Очистить журнал" (чистит и сам журнал, и реальные сообщения в чате).

## 4. Музыка (заказ песен + плейлист + виджет)

- **Заказ треков зрителями**: команда `!sr <ссылка>` (или своя команда —
  настраивается) — YouTube-ссылки и ссылки Spotify (для Spotify через
  oEmbed находится название трека, затем ищется совпадение на YouTube).
- Настраиваемые критерии для заказа (обходятся модераторами/стримером/
  суперадмином):
  - только подписчики,
  - минимальное число просмотров видео,
  - максимальная длительность,
  - только категория «Музыка» на YouTube,
  - чёрный список каналов YouTube,
  - кулдаун между заказами одного зрителя,
  - автоудаление сообщения-заказа и ответа бота через N секунд (антиспам
    ссылками в чате).
- **Очередь** — реальная очередь, treki проигрываются по порядку.
- **Фоновый плейлист** — свой список треков стримера, зацикливается
  (по порядку или вперемешку), включается сам, когда очередь опустела, и
  не мешает виджету «застыть» без звука.
- **Пауза/возобновление** — с сервера, синхронно применяется на виджете
  (не через перезагрузку страницы), с честным пересчётом времени, "сколько
  играет" (не учитывает время на паузе).
- **«Стоп»** — полностью останавливает воспроизведение (не просто пауза).
- **Пропустить трек** — вручную, или автоматически по окончании.
- **Реальная громкость** — задаётся на дашборде, применяется к плееру
  YouTube на виджете напрямую (`setVolume`/`unMute`).
- **!song / аптайм-команды** — готовые к использованию текстовые команды
  бота ("что сейчас играет", "сколько идёт стрим").

## 5. Виджеты для OBS (все — постоянные ссылки, настройки живут на сервере)

- **Чат** (`/widget/chat`) — реальный оверлей чата, WebSocket-подключение
  к Durable Object канала, показывает сообщения вживую. Настройки: акцент,
  прозрачность, размер шрифта, шрифт, анимация появления, скругления,
  макс. строк, бейджи, таймстемпы, тень, скрывать команды/сообщения бота.
- **Музыка / «Сейчас играет»** (`/widget/now-playing`) — обложка, название,
  прогресс-бар (по реальному времени плеера), "далее в очереди", авто-скрытие,
  громкость, глянец/layout, компакт-режим.
- **Аукцион** (`/widget/auction`) — см. ниже.
- **Донат-алерт** (`/widget/donation-alert`) — всплывающая карточка на
  донат, с картинкой/звуком по порогам суммы.
- **Прогресс-бар цели** (`/widget/donation-goal`) — реальный расчёт от
  суммы донатов.
- **Оповещения с озвучкой (Text-to-Speech)** (`/widget/announce`) —
  создаётся в админ-панели: полностью прозрачное окно, куда админ
  вручную отправляет текст → он появляется на экране и озвучивается
  голосом, затем сам исчезает до следующего сообщения.
  - Общий голосовой движок (используется тут и в команде `!vl`): подбирает
    женский голос отдельно для русского и английского (по базе известных
    имён голосов, т.к. Web Speech API не даёт явно указать пол), режет
    смешанный текст на куски по языку и озвучивает каждый своим голосом,
    смягчённый тон (чуть выше pitch, чуть ниже rate).
  - `!vl <текст>` — команда в чате, тот же голосовой движок, тоже через
    чат-виджет.

## 6. DonationAlerts (донаты)

- Подключение через OAuth DonationAlerts.
- Реальная статистика донатов (суммы, топ).
- Оповещение о донате в чате (можно включить/выключить, минимальная сумма
  для анонса).
- Виджет доната с картинками/звуками по правилам (порог суммы → своя
  картинка/звук).
- Цель сбора (прогресс-бар) — с виджетом.
- Загрузка своих медиафайлов (картинки/звук) для алертов — с раздачей
  через `/media/...`.

---

## 7. Аукционы (в стиле pointauc)

- Мульти-опции (несколько вариантов ставок одновременно), таймер, статусы
  (идёт/завершён), победитель по наивысшей ставке или "колесо".
- Ставки через Twitch Channel Points (создание/чтение реальной награды
  каналов поинтов через Helix).
- Публичный виджет для OBS с live-обновлением ставок и анимацией результата.

---

## 8. Админ-панель (`/admin`, доступ: суперадмин + назначенные админы)

- Таблица всех пользователей платформы: статус подключения к Twitch,
  вкл/выкл бота, тариф.
- **Полная карточка пользователя** (открывается кликом): профиль Twitch,
  тариф (с изменением), вся модерация, таймеры, команды, музыка (очередь,
  настройки заказа), виджет-настройки, действия:
  - перезагрузить бота,
  - проверить подключение (тестовое сообщение),
  - заблокировать/разблокировать доступ к сайту (с причиной),
  - отвязать Twitch,
  - выдать/забрать доступ к самой админ-панели (только суперадмин).
- **Ручной бан/разбан в чате** — по любому подключённому каналу.
- **Рассылка уведомлений** — всем пользователям или одному.
- **Платформенный чёрный список** — глобальные юзернеймы для авто-бана.
- **Оповещения для OBS (TTS)** — создание/удаление ссылок-«слотов»,
  отправка текста в конкретный слот (см. раздел 5).

## 9. Прочее

- Страница условий использования (`/terms`).
- Отдельная страница для заблокированных пользователей (`/blocked`).
- Видимый репортер ошибок JS прямо на экране (без DevTools) — если
  что-то падает при загрузке, видно реальный текст ошибки.
- Баннер техработ — скрыт для суперадмина, чтобы тестировать вживую, не
  пугая остальных пользователей во время правок.
