# Промт для создания сайта бота для стримеров

> Скопируй текст ниже и отправь как задание на разработку. Сейчас реализуется только **главная страница**; остальные разделы описаны, чтобы ссылки и меню вели в правильные места.

---

## Задача

Разработай главную страницу сайта **Streop**, чат-бота и набора инструментов для стримеров (Twitch, YouTube, VK Play). Сайт должен работать как статический (HTML + CSS + JS без сборки), чтобы его можно было загрузить на виртуальный хостинг REG.RU в папку `public_html`.

## Технологии

- Чистый HTML5, CSS3 (custom properties) и JavaScript (ES2020) без фреймворков и сборщиков
- Шрифты подключаются через Google Fonts, иконки встроены в страницу как SVG
- Без бэкенда: авторизация и настройки в демо-режиме хранятся в `localStorage`
- Адаптивная вёрстка: 375 / 768 / 1024 / 1440 px, без горизонтального скролла
- **Стиль и цвета:** тёмная тема по умолчанию (как в ТЗ квест-сайта), светлая как вариант. Тёплый почти чёрный фон `#0d0b0b`, светлый текст `#efe9e3`, один тёмно-красный акцент `#c8102e` (кнопки, курсивные акценты в заголовках, номера, выделенный тариф). Без градиентов, на главном экране тёмный оверлей-виньетка по краям
- Минимализм: тонкие линии в 1 px, крупная типографика (Inter Tight + курсив Instrument Serif), моноширинные подписи (JetBrains Mono)
- Вся палитра строится из трёх цветов (фон, текст, кнопки), которые пользователь может поменять сам; учитывается `prefers-reduced-motion`

## 1. Хедер (фиксированный)

- **Слева:** логотип и название сайта; клик ведёт на главную
- **По центру:** якорные ссылки «Возможности», «Тарифы». На мобильных они прячутся в burger-меню
- **Справа:** вид зависит от статуса авторизации
  - **Не авторизован:** кнопка «Войти»
  - **Авторизован:** круглый аватар пользователя. По клику открывается выпадающее меню стримера:
    - «Панель стримера»: переход в личный кабинет
    - «Мои стримеры»: список отслеживаемых каналов
    - «Настройки»: параметры аккаунта и бота (открывается модальное окно)
    - «Выйти»: выход из аккаунта
  - Меню закрывается по клику вне него и по `Esc`, им можно управлять с клавиатуры

## 2. Настройки аккаунта (модальное окно с вкладками)

1. **Аккаунт:** имя, e-mail, подключённая платформа, дата регистрации, ID аккаунта
2. **Оформление:** пользователь настраивает сайт как захочет
   - готовые стили: «Тёмная» (по умолчанию), «Светлая», «Чёрная», «Белая»
   - свои цвета: фон сайта, текст, кнопки (color-picker); второстепенные оттенки и линии вычисляются автоматически
   - шрифт заголовков и основного текста
   - скругление углов: 0 / 6 / 14 / 28 px
   - размер текста: 14–19 px
   - порядок блоков на главной и их скрытие
   - название сайта и свой логотип
   - кнопка «Сбросить оформление»
3. **Баланс:** текущие средства, активная подписка с датой продления, история пополнений и списаний
4. **Удаление аккаунта:** нужно ввести слово `УДАЛИТЬ`, после чего все данные стираются без возможности восстановления

Изменения применяются сразу и сохраняются между визитами.

## 3. Hero-секция (100vh)

- Подпись «Бот для Twitch · YouTube · VK Play» и огромное название сайта на всю ширину
- Под тонкой линией слева: питч с курсивным акцентом, кнопка «Продолжить» (если не вошёл, открывает вход, если вошёл, ведёт в «Панель стримера») и ссылка «Тарифы»
- Справа: три цифры (10 модулей, 3 платформы, 24/7)

## 4. Блок «Преимущества бота»

Заголовок: «Всё, что нужно стримеру, в одном месте». Сетка из 10 карточек с иконками и подсветкой при наведении:

| Модуль | Описание |
|---|---|
| Модерация чата | Автоматическая фильтрация спама, мата, рекламы и капса |
| Аналитика чата | Статистика активности, топ зрителей, пиковые часы |
| Виджеты | Готовые оверлеи для OBS: цели, донаты, подписки, топы |
| Музыка | Управление треками прямо из чата командами |
| Таймеры и команды | Автосообщения, счётчики, кастомные команды |
| Розыгрыши | Проведение Giveaway с автоподбором победителей |
| Автоответы | Реакция на ключевые слова и приветствие новых зрителей |
| Уведомления | Алерты о донатах, фолловах, сабах и рейдах |
| Единый дашборд | Все настройки и модули в одном окне |
| Мультиплатформенность | Поддержка Twitch, YouTube и VK Play |

## 5. Блок «Уровни подписок»

Три карточки. Средняя («Про») выделена как рекомендуемая.

**Продвинутая: 299 ₽/мес.** Оптимальный старт для растущего стримера.
- Все виджеты без ограничений
- ИИ-модерация: умная фильтрация спама, токсичности и рекламы
- Аналитика чата за 30 дней: активность, топ зрителей, пиковые часы
- Музыка, команды, таймеры, розыгрыши, автоответы
- Базовые алерты: донаты, фолловы, сабы

**Про: 499 ₽/мес.** Для стримеров, которые хотят расти и понимать свою аудиторию.
- Всё из тарифа «Продвинутая»
- Своя страница стримера: личный лендинг с информацией о канале, расписанием и ссылками
- Аналитика каждого зрителя: история активности, донаты, время просмотра, вовлечённость
- Расширенная статистика по каналу и чату
- Кастомизация виджетов под свой бренд

**Максимум: 967 ₽/мес.** Всё, что есть в боте, без ограничений.
- Всё из тарифа «Про»
- Полный доступ ко всем функциям и модулям
- Приоритетная поддержка 24/7
- Ранний доступ к новым фишкам
- Индивидуальные интеграции под твой канал
- Аналитика без ограничений по глубине и детализации

Под карточками идёт строка краткого сравнения:
**299 ₽**: все инструменты для работы со стримом · **499 ₽**: персональная страница и глубокий разбор аудитории · **967 ₽**: абсолютный максимум возможностей.
