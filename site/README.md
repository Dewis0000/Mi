# Streop: главная страница

Статический сайт (HTML + CSS + JS), сборка не нужна.

```
site/
├── index.html      — главная страница
├── css/style.css   — стили
├── js/main.js      — меню, вход, настройки, анимации
├── favicon.svg
└── .htaccess       — сжатие и кэш для Apache (REG.RU)
```

## Как загрузить на REG.RU

1. Зайдите в панель хостинга (ISPmanager): «Менеджер файлов» → папка `www/ваш-домен.ru/` (на некоторых тарифах `public_html`).
2. Удалите оттуда стандартную заглушку `index.html`, если она есть.
3. Загрузите **содержимое** папки `site/`: `index.html`, `favicon.svg`, `.htaccess`, папки `css` и `js`. Удобнее всего сжать их в zip, загрузить архив и распаковать его прямо в менеджере файлов.
4. Откройте домен в браузере.

Файл `.htaccess` начинается с точки и может быть скрыт в проводнике. Включите показ скрытых файлов, чтобы его не потерять.

## Посмотреть локально

Откройте `index.html` в браузере двойным кликом или запустите `python3 -m http.server` в папке `site`.

## Демо-режим

Бэкенда пока нет. Кнопка «Войти» создаёт демо-аккаунт, а аккаунт и настройки оформления хранятся в `localStorage` браузера. «Панель стримера», «Мои стримеры» и оплата тарифов показывают уведомление «скоро появится». Когда появится бэкенд, замените функции `login`, `logout` и обработчики настроек в `js/main.js` на запросы к API.

## Что поменять под себя

- Название и логотип можно сменить прямо на сайте («Настройки» → «Оформление») или в `index.html` (текст `Streop`).
- Цвета по умолчанию задаются тремя переменными в начале `css/style.css`: `--bg` (фон), `--fg` (текст), `--accent` (кнопки). Остальные оттенки вычисляются из них.
- Голова робота рисуется в `js/main.js` (блок «3D-голова робота из точек»).
- Почта поддержки указана в подвале `index.html`.
