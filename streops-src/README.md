# Hearth на streops.ru/dsZov/

Чат, личные звонки и голосовые комнаты: сообщения в реальном времени, эмодзи-реакции Ember, звонки с камерой и демонстрацией экрана, никнеймы с уникальным ID.

## Что нужно

- **VPS, а не обычный shared-хостинг Reg.ru.** Приложению нужен долгоживущий процесс Node.js и WebSocket. Обычный хостинг отдаёт только статику, поэтому сообщения и звонки на нём не заработают. На VPS Reg.ru всё работает.
- Ubuntu 22.04/24.04 или Debian, доступ root или sudo.
- Домен `streops.ru`, указывающий на этот сервер, и HTTPS. Без HTTPS браузер не даст доступ к микрофону и камере.
- Node.js 18+. Если его нет, `install.sh` установит Node.js 20.

## Установка

На сервере, в папке репозитория:

```bash
cd ~/streops-src && git pull && bash ~/streops-src/server/install.sh
```

Скрипт:
1. Ставит Node.js, если его нет.
2. Ставит зависимости (`npm ci`).
3. Создаёт `.env` и папку `data/` с данными.
4. Создаёт службу `streops-dszov` (systemd), которая запускает сервер на `127.0.0.1:3100` и перезапускается сам.
5. Проверяет, что сервер отвечает.
6. Записывает `/etc/nginx/snippets/streops-dszov.conf` с location `/dsZov/`.

Повторный запуск безопасен: зависимости обновятся, служба перезапустится, `.env` не перезаписывается.

### Два шага вручную (один раз)

**1. Подключить location к сайту streops.ru.** Открой конфиг сайта (например, `/etc/nginx/sites-enabled/streops.ru`). Внутрь блока `server { ... }` с HTTPS добавь строку:

```nginx
include /etc/nginx/snippets/streops-dszov.conf;
```

Проверь и перезагрузи nginx:

```bash
sudo nginx -t && sudo systemctl reload nginx
```

**2. HTTPS.** Если сертификата ещё нет:

```bash
sudo apt-get install -y certbot python3-certbot-nginx
sudo certbot --nginx -d streops.ru
```

Готово: **https://streops.ru/dsZov/**

## Как устроено

```
streops-src/
├── public/              # клиент, без сборки
│   ├── index.html       # разметка: вход, приложение, окно звонка, настройки
│   ├── app.css          # стили и темы
│   ├── app.js           # чат, звонки (WebRTC), настройки
│   └── icon.svg
├── server/
│   ├── index.js         # HTTP (статика, API) + WebSocket (сообщения, сигналинг)
│   ├── install.sh       # установка на сервер
│   └── nginx-dszov.conf.template
├── tests/e2e.js         # сквозной тест в двух браузерах
├── data/                # db.json: пользователи и сообщения (создаётся сам)
├── .env                 # настройки сервера (создаёт install.sh)
└── package.json
```

- **Регистрация.** Ник → уникальный ID вида `nova#K7Q2M9`. Код проверяется на сервере, два одинаковых ID не выдаются. Смена ника ID не меняет.
- **Сообщения.** Идут по WebSocket по адресу `/dsZov/ws`. Хранятся по 500 последних в каждом канале в `data/db.json`.
- **Звонки.** Сервер только передаёт сигналы (SDP и ICE). Аудио и видео идут напрямую между браузерами по WebRTC, сервер их не видит. Комната до 8 участников.
- **Личный звонок.** Звонящий создаёт комнату и посылает кольцо. Собеседник принимает или отклоняет. Нет ответа за 40 секунд, звонок отменяется.
- **Голосовые комнаты.** Например, Campfire. Заходишь и выходишь, когда хочешь.

## Настройки (.env)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `PORT` | `3100` | порт Node, только на localhost |
| `BASE_PATH` | `/dsZov` | путь, по которому отдаётся приложение |
| `DATA_DIR` | `./data` | где лежит `db.json` |
| `STUN_URLS` | Google STUN | серверы STUN через запятую |
| `TURN_URLS`, `TURN_USERNAME`, `TURN_CREDENTIAL` | пусто | свой TURN, см. ниже |

После изменения `.env`: `sudo systemctl restart streops-dszov`.

## TURN: если звонки не соединяются

У части людей, особенно через мобильный интернет или корпоративные сети, прямое соединение не проходит. Тогда нужен TURN-сервер (coturn), который будет передавать медиа. На том же VPS:

```bash
sudo apt-get install -y coturn
```

В `/etc/turnserver.conf` (замени IP и пароль):

```
listening-port=3478
fingerprint
lt-cred-mech
realm=streops.ru
user=hearth:ДЛИННЫЙ-СЛУЧАЙНЫЙ-ПАРОЛЬ
external-ip=ПУБЛИЧНЫЙ_IP_VPS
min-port=49160
max-port=49200
```

Открой в фаерволе порты 3478 (TCP и UDP) и 49160–49200 (UDP). Затем раскомментируй `TURN_*` в `.env` и перезапусти службу.

## Если что-то не работает

- **Нет доступа к микрофону или камере.** Нужен HTTPS, см. шаг 2.
- **Звонок «соединяем…» и не соединяется.** Нужен TURN, см. выше.
- **Сайт отдаёт 502.** Проверь, что служба работает: `sudo systemctl status streops-dszov`, и что `PORT` в `.env` совпадает с `proxy_pass` в nginx.
- **Служба не запускается.** Смотри лог: `sudo journalctl -u streops-dszov -n 100 --no-pager`.

## Ограничения, о которых стоит знать

- **Вход без пароля.** Ключ входа хранится в браузере. Если очистить данные сайта, аккаунт станет недоступен. Вход с нескольких устройств и восстановление пока не сделаны.
- **Сообщения хранятся на сервере в открытом виде.** Сквозного шифрования текста нет. Медиа в звонках шифруется WebRTC, но это не то же самое.
- **Хранилище — один JSON-файл.** Для небольшой группы подходит. Для тысяч пользователей нужна база данных.
- **Резервная копия.** Копируй `data/db.json`, например `cp data/db.json ~/backup-$(date +%F).json`.
