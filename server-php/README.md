# Боевой сайт Neru-Квест — backend (PHP + MySQL)

Это серверная часть сайта **nery-quest.ru**: тот же красивый React-сайт, но с
реальной работой — регистрация, вход, онлайн-запись, расчёт цены, предоплата,
уведомления оператору в Telegram/MAX и админ-панель.

Работает на обычном хостинге reg.ru (PHP 8.1+ и MySQL). Node.js нужен **только
на вашем компьютере** для сборки фронтенда — на хостинге он не требуется.

---

## Что где лежит

```
server-php/
  public/          ← то, что видно в интернете (корень сайта)
    index.html, assets/, images/   — собранный React (кладётся build.sh)
    .htaccess                      — маршруты и защита
    api/index.php                  — API (/api/...)
  lib/             ← логика сервера (вне интернета)
  config.example.php ← шаблон настроек (скопировать в config.php)
  build.sh         ← сборка фронтенда
```

Клиенты и брони хранятся в **MySQL** (таблицы создаются сами при первом
запросе). Тексты, цены и квест — в `lib/data.php`. Секреты (пароль БД, токены
ботов) — только в `config.php` на сервере, в репозиторий он не попадает.

## Деплой за 5 шагов

### 1. Собрать фронтенд (на своём компьютере)
```bash
bash server-php/build.sh
```
React соберётся и попадёт в `server-php/public/`.

### 2. Создать базу MySQL
В панели reg.ru → **MySQL** создайте базу и пользователя (или используйте
существующую). Запишите: имя базы, пользователя, пароль, хост (обычно
`localhost`).

### 3. Заполнить config.php
Скопируйте шаблон и впишите реальные значения:
```bash
cp server-php/config.example.php server-php/config.php
```
Обязательно:
- `db` — данные из шага 2;
- `app_secret` — длинная случайная строка (например, выполните
  `php -r "echo bin2hex(random_bytes(32));"` и вставьте результат);
- `owner_phones` — номер(а) владельца (по умолчанию `+79996544460`);
- `venue_tz` — `Asia/Yakutsk` (уже стоит).

### 4. Загрузить файлы на хостинг
**Вариант A (рекомендуется, безопаснее).** Загрузите всю папку `server-php/`
и в панели (ispmanager → сайт nery-quest.ru → **Корневая директория**) укажите
путь до `server-php/public`.

**Вариант B (если корень сайта поменять нельзя).** В корень сайта
(`.../www/nery-quest.ru/`) положите **содержимое** `public/` (файлы index.html,
папки assets, images, api, файл .htaccess), а рядом — папку `lib/` и файл
`config.php`. Они закрыты от интернета через `.htaccess`, а PHP их видит.
Код сам находит `lib/` в обоих вариантах — править ничего не нужно.

### 5. Первый вход
Откройте сайт → «Вход» → введите номер владельца. Код подтверждения появится
на экране (режим разработки, пока не подключён Telegram Gateway/SMS — см. ниже).
Войдите, задайте пароль в профиле — в меню появится «Админ-панель».

## Боты

### Уведомления оператору о новых бронях (Telegram и MAX)
1. Telegram: создайте бота у @BotFather, впишите его токен в
   `telegram_bot_token`. Оператор пишет боту `/start`; узнать его `chat_id`
   можно через бота @userinfobot. Впишите chat_id в
   `telegram_operator_chat_ids` (можно несколько).
2. MAX: по аналогии — `max_bot_token` и `max_operator_chat_ids`.

После этого на каждую новую запись оператору приходит сообщение с квестом,
датой, числом игроков, телефоном клиента, суммой и предоплатой.

### Код подтверждения «по номеру телефона»
Чтобы код приходил человеку в Telegram без того, чтобы он заранее писал боту,
нужен **Telegram Gateway** (https://gateway.telegram.org) — впишите его токен в
`telegram_gateway_token`. Тогда поставьте `expose_dev_codes = false`.
Пока Gateway/SMS не подключены — код показывается прямо на экране входа
(удобно для теста, сайт полностью рабочий).

## Если при регистрации / входе ошибка 500

Почти всегда это база данных (сам сайт открывается, т.к. страницы не трогают БД, а
регистрация трогает). Проверьте по шагам:

1. В `config.php` временно поставьте `'debug' => true` и повторите попытку —
   теперь вместо «500» в ответе придёт причина. Посмотреть можно в браузере:
   DevTools → вкладка Network → запрос `verify`/`code` → Response.
2. Частые причины и что показывает ответ:
   - `code: DB_CONNECT` — неверные имя базы / пользователь / пароль / хост в
     `config.php` (блок `db`). Исправьте их.
   - `code: DB_SCHEMA` — у пользователя БД нет прав на создание таблиц. Импортируйте
     `server-php/schema.sql` через phpMyAdmin (панель reg.ru → phpMyAdmin → ваша база
     → Импорт).
   - другой текст с `SERVER_ERROR` — пришлите его, разберём.
3. Детали ошибок всегда дублируются в файл `lib/error.log` (он закрыт от интернета).
4. После починки верните `'debug' => false`.

## Безопасность
- `config.php` никогда не коммитится (он в `.gitignore`).
- **Смените** все пароли и токены, которые раньше пересылались в переписке
  (пароль БД, FTP, токены ботов) — считайте их скомпрометированными.
- Сайт работает только по HTTPS (редирект настроен в `.htaccess`).

## Обновление
Поменяли тексты/цены/квест в `lib/data.php` или код — пересоберите фронт
(`bash server-php/build.sh`, если меняли React) и перезалейте изменённые файлы.
Данные клиентов и брони в базе при этом не трогаются.
