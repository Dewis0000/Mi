# Выпендрёж 🦚

Своя игра для тех, кто любит выпендриваться перед друзьями. Этот репозиторий
сейчас на этапе **дизайна**: фронтенд с демо-данными, без бэкенда и настоящей
авторизации. Все экраны кликабельны и работают на моках.

## Стек

- **Next.js 16** (App Router, TypeScript, Turbopack) + **Cache Components**
- **Tailwind CSS v4** (CSS-first конфиг в `src/app/globals.css`)
- **shadcn/ui** на базе **Base UI** (а не Radix — используйте проп `render`
  вместо `asChild` для полиморфных компонентов)
- **Framer Motion** — скролл-анимации
- **React Hook Form + Zod** — формы регистрации/входа
- **next-themes** — светлая/тёмная/системная тема
- **canvas-confetti**, **lucide-react**, **zustand** (пока не используется, задел на будущее)

## Структура

```
src/
  app/                     # страницы (App Router)
    page.tsx               # лендинг
    login/, register/      # формы входа/регистрации (моки)
    dashboard/             # "Мои игры" + вход по коду
    play/demo/              # интерактивное игровое поле
    create/                 # редактор своего пакета вопросов
    hall-of-shame/          # Зал Позора
  components/
    ui/                    # shadcn/ui примитивы
    game/                  # доска, вопрос-модалка, баззер, редактор пакета
    auth/                  # формы входа/регистрации
  lib/demo-data.ts         # демо-пакет вопросов, игроки, Зал Позора, реплики маскота
```

## Запуск локально

```bash
pnpm install
pnpm dev
```

Откройте [http://localhost:3000](http://localhost:3000).

```bash
pnpm build   # продакшн-сборка
pnpm start   # запуск собранного проекта
pnpm lint    # ESLint
```

## Переменные окружения

Пока не требуются — бэкенда, базы данных и реальной авторизации ещё нет.
Когда они появятся, здесь будет `.env.example`.

## Деплой

Проект — обычное Next.js-приложение, разворачивается на Vercel (`vercel deploy`)
без дополнительной настройки, либо на любом хостинге с поддержкой Node.js
(`pnpm build && pnpm start`).
