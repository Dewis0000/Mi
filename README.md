# Один из восьми миллиардов

Браузерный симулятор одной случайной человеческой жизни на реальной
демографической статистике. Полностью клиентское приложение — бэкенда нет,
ключ ИИ (если он включён) никогда не покидает браузер и уходит напрямую
только выбранному провайдеру.

## Стек

React 18 + TypeScript (strict) + Vite, Zustand, Tailwind CSS, Recharts,
Dexie (IndexedDB), Vitest.

## Локальный запуск

```bash
npm install
npm run dev       # дев-сервер
npm run build     # прод-сборка в dist/
npm test          # движок: вероятностные тесты из раздела 9/18 спецификации
```

## Структура

- `src/types.ts` — контракт данных между движком, ИИ-слоем и интерфейсом.
- `src/data/` — демографические данные: 197 стран, 183 региона в 40
  крупнейших странах, 31 культурный пакет, 16 причин смерти. См.
  `src/data/SOURCES.md` про происхождение и погрешность цифр.
- `src/engine/` — детерминированный движок: RNG (mulberry32), генератор
  рождения, калиброванная параметрическая модель смертности, выбор событий,
  применение эффектов, движок времени. Ни одного `Math.random()`.
- `src/events/` — оффлайн-пул из 407 событий (12 категорий), двуязычный
  (ru/en), с ~30 сцепками "событие открывает событие" через систему traits.
- `src/ai/` — слой ИИ: 4 провайдера (OpenAI, Anthropic, Google, OpenRouter)
  + свой endpoint, подсчёт токенов и бюджета, пост-фильтр безопасности
  контента, оффлайн-фолбэк.
- `src/store/` — Zustand-стор, склейка движка с ИИ/оффлайн-резолюцией
  текста, автосохранение, журнал жизней (Dexie).
- `src/components/` — экраны и общие компоненты интерфейса.
- `server/install.sh` — деплой на хостинг nery-quest.online (см. ниже).

## Деплой на nery-quest.online

Хостинг — reg.ru / ISPmanager. По SSH, на сервере:

**Первый раз** (клонирует репозиторий и сразу собирает/публикует сайт):

```bash
git clone -b claude/fervent-knuth-sv7rh9 https://github.com/Dewis0000/Mi.git ~/nery-src
bash ~/nery-src/server/install.sh
```

(после того как ветка `claude/fervent-knuth-sv7rh9` смёржится в основную — клонируйте без `-b <ветка>`, по умолчанию возьмётся основная ветка репозитория)

**Каждое следующее обновление:**

```bash
cd ~/nery-src && git pull && bash server/install.sh
```

Скрипт сам: проверяет node/npm, ставит зависимости, собирает `dist/`,
находит докрут домена (перебирает несколько типичных путей ISPmanager) и
копирует туда билд. Node нужен только во время сборки — само приложение
статическое, никакого постоянно работающего процесса на сервере не требует.

Если скрипт не находит докрут автоматически — он честно останавливается и
печатает, какие пути проверил; поправьте `CANDIDATE_DOCROOTS` в
`server/install.sh` под реальный путь из ISPmanager (WWW-домены →
nery-quest.online → путь/домашняя директория).

## Известные ограничения

Честно, а не молча:

- **Таблицы смертности.** Вместо статичного qx по возрастным полосам для
  195 стран (что потребовало бы придумать тысячи чисел, которые нельзя
  проверить) используется параметрическая кривая, откалиброванная под
  настоящие lifeExpectancy/infantMortality каждой страны. Проверено тестами
  из раздела 9/18 — не взято из воздуха, но это модель, а не архивные данные.
- **Редкость по децилю** в карточке рождения считается как фиксированная
  1/10, а не точная плотность бета-распределения в этой точке — ради
  декоративного числа это не стоило сложности функции Β(a,b).
- **Батчинг ИИ-запросов.** Экономия "несколько событий одного тика — один
  запрос, не три" не реализована как единый батч-запрос; вместо этого —
  независимые запросы с кэшем по контексту в sessionStorage и строгое
  правило "minor — всегда оффлайн". Укладывается в дух раздела 12, но не
  буквально.
- **Пост-фильтр контента** эвристический (regex по ru/en), не
  семантический — ловит прямые формулировки запрещённого раздела 16
  контента, но не гарантирует ничего против творчески обфусцированного
  текста. Настоящий барьер — оффлайн-пул, написанный вручную безопасным
  с самого начала; ИИ только поверх него.
- **"Лет обучения"/"дециль на пике"** в эпилоге выводятся из характеристик
  персонажа (education/wealth 0–100), а не хранятся как отдельная история —
  честные производные величины, а не отдельно отслеживаемые факты.
