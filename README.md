# Лабиринт — сайт квест-клуба

Многостраничный сайт сети квестов: каталог и бронирование, личный кабинет с баллами
за посещения, прямой эфир и продажа видео с камер, админ-панель, онлайн-оплата с
фискальными чеками (54-ФЗ). Полное описание системы — в [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

## Стек

Next.js 16 (App Router, TypeScript) · Tailwind CSS v4 + shadcn/ui (Base UI) · Prisma ORM 7 +
PostgreSQL · Auth.js (next-auth v5) · Framer Motion · React Hook Form + Zod · hls.js.

## Быстрый старт (локально)

Нужны Node.js 22+ и локальный PostgreSQL.

```bash
npm install

cp .env.example .env
# заполните DATABASE_URL и AUTH_SECRET (минимум) — см. комментарии в .env.example

npx prisma migrate dev   # применит миграции к базе
npx prisma db seed       # заполнит демо-данными (квесты, слоты, тестовые аккаунты)

npm run dev              # http://localhost:3000
```

### Тестовые аккаунты (после сидирования)

## Переменные окружения

Полный список с комментариями — в [`.env.example`](.env.example). Минимум для запуска:
`DATABASE_URL`, `AUTH_SECRET`. Остальное (VK ID/Яндекс ID/Telegram, ЮKassa) — опционально,
без них сайт работает в демо-режиме (вход по телефону, оплата через тестовый mock-провайдер).

## Деплой на reg.ru

Подробный чек-лист — в [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md#16-хостинг-и-деплой-на-regru).
Короткая версия:

1. Облачный VPS/VDS на reg.ru (Ubuntu LTS) — **не** бюджетный shared-хостинг, там нельзя
   держать процесс Node.js.
2. На сервере: Node.js, PostgreSQL, Nginx (reverse proxy), PM2, certbot (TLS).
3. `git clone` → `npm ci` → заполнить `.env` реальными ключами → `npx prisma migrate deploy` →
   `npm run build` → запустить через PM2.
4. Nginx проксирует домен на `localhost:3000`, certbot выпускает HTTPS.

## Что нужно донастроить перед реальным запуском

- **Оплата**: оформить договор с ЮKassa (или другим провайдером из раздела 9 архитектуры),
  вписать `YOOKASSA_SHOP_ID`/`YOOKASSA_SECRET_KEY`, настроить вебхук на
  `https://<домен>/api/payments/webhook`.
- **Вход через соцсети**: завести приложения VK ID, Яндекс ID и Telegram-бота, вписать их
  ключи в `.env`.
- **Камеры и прямой эфир**: сейчас это архитектурный каркас без реального видео (см. раздел 7
  документа) — нужно физически установить IP-камеры и поднять медиа-сервер (MediaMTX/go2rtc),
  затем прописать `hlsUrl` каждой камеры в админ-панели (`/admin/cameras`).
- **Юридические документы**: тексты оферты, политики конфиденциальности и правил
  посещения (`/legal/*`) — шаблоны для демонстрации, нужно согласовать с юристом перед запуском.
- **Реквизиты и контакты**: замените плейсхолдеры в `src/lib/site-config.ts` на реальные.

## Структура проекта

```
docs/ARCHITECTURE.md   — архитектура системы целиком
prisma/schema.prisma   — модель данных
prisma/seed.ts         — демо-данные
src/app/(site)/        — публичный сайт и личный кабинет
src/app/admin/         — админ-панель и консоль оператора
src/app/api/           — вебхук оплаты, next-auth
src/lib/                — бронирование, баллы, платежи, авторизация
src/components/        — UI-компоненты
```

## Идеи для дальнейшего развития

- Реферальная программа «приведи друга» (упомянута как идея в разделе 5 архитектуры).
